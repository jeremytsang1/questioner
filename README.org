#+TITLE: Questioner
* Description
Questioner is an application that reads a list of questions and answers and then quizzes a user over a text prompt.
* Dependencies
- GNU ~make~ >= 4.3
- [[id:][guile-json]] >= 4.7.3
* Running
** App
- From the project root run
  #+begin_src shell
make
  #+end_src
** Tests
*** All Tests
- From the project root.
  #+begin_src shell
make test
  #+end_src
*** Individual Test
#+begin_src shell
# From project root.
guile -L . tests/TEST-FILE LOG-DIRECTORY
#+end_src
